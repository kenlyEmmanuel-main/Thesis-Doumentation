# Modular Thesis Project

This repository contains the $\LaTeX$ source files for our Capstone / Thesis paper, structured modularly for multi-author collaboration, Git version control, and automated compilation.

## Project Structure
- `main.tex`: Master entry point containing the document preamble, formatting settings, and chapter inclusions.
- `references.bib`: BibTeX database for references and citations.
- `chapters/`: Individual chapter files (`ch1_intro.tex` to `ch5_conclusion.tex`).
- `figures/`: Asset folder for diagram images and charts.
- `.gitignore`: Configured to ignore temporary $\LaTeX$ compilation artifacts.

## How to Work with This Project
1. Open this folder in **Antigravity IDE** (`File` -> `Open Folder`).
2. Open `main.tex`.
3. Press `Ctrl + S` to compile (via `LaTeX Workshop`).
4. View the generated PDF side-by-side using the PDF preview button in the upper right.
